Align-content

O Align-content é a forma com que os itens se comportam dentro dos containers, alinhando os itens dentro do eixo transversal (cross-axis), quando estes estiverem empacotados.

Os exemplos que vamos usar serão utilizados com flex-flow: row nowrap

align-content: stretch;

É a forma padrão, ele estica os itens para que fiquem com a mesma dimensão e no tamanho do container:
