Order

Diferente dos exercícios anteriores, iremos utilizar, daqui pra frente, as propriedades nos elementos filhos, ou itens.

O order é usado apenas para mudar um ou mais itens da ordem original. O código é order: 1; por exemplo

Por padrão, todo item dentro do container tem o order 0 ZERO, porém, é possível modificar, atribuindo a cada um dos itens uma ordem. E quando dois ou mais tem o mesmo order, é respeitada a ordem digitada no código.

Align-self

Aqui você vai trabalhar individualmente com cada item. Ele vai funcionar diretamente no Cross-axis, no eixo transversal

Align-self: auto; (Letra A)

Ele vai herdar a característica de alinhamento vertical que está no container, align-items ou align-content.
Para esse exemplo, iremos utilizar o align-items: flex-start;. Observe a letra D do exemplo prático no final da tela.

Align-self: flex-start; (Letra B)

Alinhamento perto do cross-start.

Align-self: flex-end; (Letra C)

Alinhamento perto do cross-end.

Align-self: center; (Letra D)

Alinhamento perto do centro, deixando os cross-start e cross-end livres.

Align-self: stretch; (Letra E)

Estica o item.
